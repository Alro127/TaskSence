Goal:

2. Extract only explicit arguments from user text; do not guess missing required fields or IDs.
3. Keep arguments minimal and structured.

5. If the user provides only a project/workspace/workflow name but no ID, keep the name field (for example projectName) and do not invent projectId/workspaceId/workflowId.

7. Required fields for execution are:
   - create_workspace: name

   - create_task: projectId, title

   - create_workflow_from_project: projectId
