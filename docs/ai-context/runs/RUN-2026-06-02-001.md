## Decisions & Context
- **Semantic Mapping**: Instead of using brittle CSS selectors, the AI outputs semantic "capabilities" (e.g., `CREATE_TASK`). The frontend registry maps these to actual DOM elements at runtime.
- **Project Cloning**: Creating a project from a workflow now automatically creates a new workspace if none is provided, and resets all cloned tasks to `TODO` status to fix the issue described in `CURRENT_ISSUE_WRITTEN_BY_ME.md`.
- **Global Guidance**: The `GuidanceProvider` and `GuidanceOverlay` are mounted globally in `App.tsx` and `MainLayout.tsx` to support cross-page onboarding flows.
