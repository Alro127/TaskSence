# Use Cases (List of 46 standard Use Cases)

This document synchronizes the Use Case list from the official Documents.md file.

## 1. Authentication & Profile (Authentication & Personality)

- **UC-01 - Account registration:** Visitor registers a new account.
- **UC-02 - Login:** User logs into the system.
- **UC-03 - Logout:** The user exits the session safely.
- **UC-04 - Update personal information:** Change profile information (avatar, name...).

## 2. Workspace Management (Workspace Management)

- **UC-05 - Create workspace:** Create a new workspace.
- **UC-06 - Update workspace:** Customize workspace information.
- **UC-07 - Delete workspace:** Delete workspace (for owner).
- **UC-08 - View workspace list:** View the workspaces you participate in.
- **UC-09 - Add members to workspace:** Invite new members.
- **UC-10 - Remove member from workspace:** Removes user from workspace.
- **UC-11 - Leave workspace:** Automatically withdraw from the workspace.
- **UC-12 - Request to join workspace:** Send a request to join a workspace.
- **UC-13 - Cancel request to join workspace:** Withdraw request to join workspace.
- **UC-14 - Processing requests to join workspace:** Approve/reject applicants.

## 3. Project Management

- **UC-15 - Create project:** Create a new project in the workspace folder.
- **UC-16 - Update project:** Rename or configure project.
- **UC-17 - Delete project:** Delete a project that is no longer running.
- **UC-18 - View project list:** Display and search projects.
- **UC-19 - Add members to project:** Drag users from workspace to project.
- **UC-20 - Remove member from project:** Remove user from project.
- **UC-21 - Leave the project:** Self-withdraw from the project.
- **UC-22 - Project participation requirements:** Please allow permission to view the project.
- **UC-23 - Cancel request to participate in project:** Cancel request for permission.
- **UC-24 - Processing requests to join the project:** Approve/reject members applying to join the project.

## 4. Task & Collaboration (Task management and collaboration)

- **UC-25 - Create task:** Create a new task, assign date, description.
- **UC-26 - Update task:** Change status, change worker, edit task description.
- **UC-27 - Delete task:** Delete or archive a task.
- **UC-28 - View task list:** Displays the list of tasks in the project.
- **UC-29 - View task details:** Read detailed content and description of a task.
- **UC-30 - Comment on the task:** Discuss and mention colleagues right in the task.
- **UC-31 - Attach files to tasks:** Upload files to tasks (images, documents).

## 5. AI Support (AI professional support)

- **UC-32 - Suggesting tasks that should be done next:** AI evaluates the level and suggests what to do next.
- **UC-33 - Overload warning:** AI identifies overloaded workload and issues a warning.

## 6. Reporting (Reporting)

- **UC-34 - Create progress reports:** Export performance reports, analyze project data.

## 7. Workflow Sharing (Process Sharing)

- **UC-35 - Create workflow from project:** Export project structure into sample template.
- **UC-36 - Edit workflow:** Edit the template contents.
- **UC-37 - Share workflow:** Public process for community reference.
- **UC-38 - Explore workflow:** Browse and search the list of public templates.
- **UC-39 - View workflow details:** Show fragmented sample architecture.
- **UC-40 - Evaluate workflow:** Grading templates.
- **UC-41 - Comment workflow:** Comment in the sharing form.
- **UC-42 - Save favorite workflows:** Bookmark for later use.
- **UC-43 - Create project from workflow:** Import workflow template into your actual project.
- **UC-44 - View posted workflow:** Manage the samples you contribute.

## 8. Dashboard

- **UC-45 - View project dashboard:** See an overview of the project's completion speed.
- **UC-46 - View personal dashboard:** View charts, evaluate individual performance.
