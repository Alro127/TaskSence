# User Stories

This document maps functionality to User Stories according to a unified list of 46 Use Cases from Documents.md.

## Epic 1: Authentication & User Profile

- **UC-01 - Account registration**: As a visitor, I want to create a new account to start using the system.
- **UC-02 - Login**: As a user, I want to log in to continue my work.
- **UC-03 - Logout**: As a user, I want to securely logout to secure my account.
- **UC-04 - Update personal information**: As a user, I want to adjust my profile (change name, avatar) so that my colleagues can easily identify me.

## Epic 2: Workspace Management

- **UC-05 - Create a workspace**: As a team manager, I want to create a workspace to gather my projects in one place.
- **UC-06 - Update workspace**: As Workspace Owner, I want to edit the workspace display name and description.
- **UC-07 - Delete workspace**: As Workspace Owner, I have the right to delete the entire workspace when the team disbands.
- **UC-08 - View workspace list**: As a member, I want to quickly access the list of workspaces I participate in.
- **UC-09 - Add members to workspace**: As Workspace Owner, I want to send invitations to others to join the group.
- **UC-10 - Remove member from workspace**: As Workspace Owner, I want to revoke access rights of a departing employee.
- **UC-11 - Leave workspace**: As a member, I want to proactively leave groups that are no longer suitable.
- **UC-12 - Request to join workspace**: As a new student, I want to send a request to work in the research workspace.
- **UC-13 - Cancel request to join workspace**: As the sender, I can cancel my permission request.
- **UC-14 - Handling requests to join workspace**: As an administrator, I approve and grant permissions to valid requests.

## Epic 3: Project Management

- **UC-15 - Create project**: As a manager, I want to create a project to start managing tasks.
- **UC-16 - Project update**: As a Project Manager, I want to edit the project goal according to the actual situation.
- **UC-17 - Delete project**: As Project Manager, I have the right to delete canceled projects.
- **UC-18 - View project list**: As a user, I quickly view all projects in the workspace.
- **UC-19 - Add members to project**: As Project Manager, I drag colleagues from the workspace to a specific project.
- **UC-20 - Remove member from project**: As Project Manager, I revoke their permission to work on the project.
- **UC-21 - Leaving project**: As a member, I leave the project after completing my responsibilities.
- **UC-22 - Project participation request**: As a member, I would like to grant permission to view a private project.
- **UC-23 - Cancel request to participate in project**: I withdraw my request to participate in the project I just sent.
- **UC-24 - Processing project participation request**: PM approves or rejects the application to participate.

## Epic 4: Task & Collaboration

- **UC-25 - Create task**: As a project member, I open a new task to track work progress.
- **UC-26 - Update task**: As the assignee, I want to update the status and transfer the assignee when necessary.
- **UC-27 - Delete task**: As the task creator, I delete redundant and error tickets.
- **UC-28 - View task list**: As a member, I want to open the interface in list and kanban format for global view.
- **UC-29 - View task details**: As the person doing the task, I want to open the details to read the description carefully.
- **UC-30 - Comment on task**: As a teammate, I leave a comment under the task to update the situation or ask questions.
- **UC-31 - Attach files to the task**: I upload the quote and graphic files to the task for the team to see.

## Epic 5: AI Support

- **UC-32 - Suggested tasks to do next**: As a multi-tasking individual, I want AI to analyze deadlines to advise me on what to do right now.
- **UC-33 - Overload warning**: As a Project Manager, I want to receive insight if any member is overloaded beyond capacity so I can promptly coordinate.

## Epic 6: Reporting

- **UC-34 - Create progress report**: As a team leader, I want to have a slide report on the team's % completion on the weekend evening.

## Epic 7: Workflow Sharing

- **UC-35 - Create workflow from project**: As a professional individual, I want to turn my project structure into a sample Workflow Template.
- **UC-36 - Edit workflow**: I want to reconfigure the template's descriptions to make them more general.
- **UC-37 - Share workflow**: I set Public mode so that my template appears in the community repository.
- **UC-38 - Discover workflow**: As a student new to management, I look for good templates with good reviews.
- **UC-39 - View workflow details**: I open the overview of the number of tasks in a shared workflow.
- **UC-40 - Workflow review**: I vote 5 stars for this useful process template.
- **UC-41 - Workflow comment**: I want to ask the author of the workflow about the applicable meaning of a task.
- **UC-42 - Save favorite workflow**: I bookmarked this workflow so I can remember it later.
- **UC-43 - Create project from workflow**: I clone the sample process to create a 1-1 Project Workspace instantly.
- **UC-44 - View posted workflows**: I open the list to manage the workflows I have contributed.

## Epic 8: Dashboards

- **UC-45 - View project dashboard**: As a manager or member, I look at the summary data chart right outside the project screen.
- **UC-46 - View personal dashboard**: As an individual, I track the speed and volume of my assigned work.
